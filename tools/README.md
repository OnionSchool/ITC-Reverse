# 离线抓包

本目录的脚本只启动抓包工具，不发送报文、不启动旧服务、不改写旧安装目录或 MDB。没有公网是预期的安全条件；测试网络应使用仅主机网络或一台独立交换机，且不要配置默认网关、DNS 或 NAT。

## 离线准备

在可联网的另一台电脑下载与测试机架构一致的 Wireshark Portable 和 Npcap 离线安装包，然后通过 U 盘带入测试环境。安装 Npcap 时只需启用抓包驱动；无需安装任何网络服务。将 Portable 版目录中的 `dumpcap.exe` 复制到本目录，或执行脚本时用 `-Dumpcap` 给出绝对路径。

## 拓扑

将旧服务端、管理端和至少一台已授权终端置于同一个完全隔离的二层网段。例如静态地址可使用 `10.77.0.10/24`、`10.77.0.20/24` 和 `10.77.0.30/24`；所有机器的默认网关和 DNS 均留空。开始前在 Windows 防火墙中仅允许测试网卡的本地流量，并确认没有 Wi-Fi、VPN、蓝牙网络或 NAT 适配器连接。

## 执行

以管理员身份打开 Windows PowerShell，在此目录执行：

```powershell
.\list-capture-interfaces.ps1 -Dumpcap .\dumpcap.exe
.\capture-itc.ps1 -Dumpcap .\dumpcap.exe -Interface 1
```

选择连接隔离网段的接口编号。脚本只保留 TCP `8000`、TCP `15001` 和目标为 `225.101.1.0/24` 的 UDP 组播流量，输出 `.pcapng` 以及对应的 SHA-256 文件到 `captures/`。启动抓包后，手动在旧管理端执行一次登录、创建会话、添加终端、开始/停止播放，再按 `Ctrl+C` 停止。

## 交付与分析

先保留原始 `.pcapng` 和 `.sha256`，复制副本再分析。使用 Wireshark 的显示过滤器依次检查：

```text
tcp.port == 8000
tcp.port == 15001
ip.dst >= 225.101.1.1 && ip.dst <= 225.101.1.253
```

脱敏后提供包含一次完整操作的 PCAP、测试网段说明、管理端/服务端/终端各自 IP、操作时间顺序和旧版本号即可。不要提供数据库、明文密码、真实校园 IP、录音或媒体文件。
